# Абсолютное значение int64

Добавить `Abs(n int64) (int64, error)` в пакет calculator. Вернуть точное математическое абсолютное значение, если оно в диапазоне int64; иначе вернуть 0 и существующий `ErrOverflow`.

Критерии: Abs(−7) = 7, Abs(0) = 0, Abs(7) = 7, Abs(MaxInt64) = MaxInt64; Abs(MinInt64) возвращает ErrOverflow. Добавить тесты; изменения только в `src/` и `tests/`.
