# Вычитание int64

Добавить `Subtract(a, b int64) (int64, error)` в пакет calculator. Вернуть точное математическое значение `a - b`, если оно в диапазоне int64; иначе вернуть 0 и существующий `ErrOverflow`.

Критерии: 5 − 3 = 2; 2 − 5 = −3; MinInt64 − 1 и MaxInt64 − (−1) возвращают ErrOverflow; MinInt64 − MinInt64 = 0 и MaxInt64 − MaxInt64 = 0 без ошибки. Добавить тесты, существующая функция Add работает как прежде. Изменения только в `src/` и `tests/`.
