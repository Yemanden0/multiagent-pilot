# Умножение int64

Добавить `Multiply(a, b int64) (int64, error)` в пакет calculator. Вернуть точное математическое значение `a * b`, если оно в диапазоне int64; иначе вернуть 0 и существующий `ErrOverflow`.

Критерии: 3 × (−4) = −12; любое значение × 0 = 0; MaxInt64 × 1 и MinInt64 × 1 возвращаются без ошибки; MinInt64 × (−1) и MaxInt64 × 2 возвращают ErrOverflow. Проверить оба порядка операндов и добавить тесты. Изменения только в `src/` и `tests/`.
