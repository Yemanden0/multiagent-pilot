# Multiagent pilot: калькулятор

Небольшой учебный Go-модуль для проверки процесса изменения кода. Это целевой репозиторий пилота, не оркестратор и не Agent-Runner. Зависимости вне стандартной библиотеки отсутствуют; требуется Go 1.24.

Пакет `src/calculator` предоставляет `Add(a, b int64) (int64, error)`. Если точная сумма не помещается в int64, функция возвращает ноль и `calculator.ErrOverflow`; иначе возвращает сумму и nil. Тесты находятся в `tests/`.

Проверки из корня репозитория:

```sh
make build
make lint  # gofmt и go vet
make test
```

Задачи для будущих изменений описаны в `docs/demo-issues/`. Первые три содержат критерии и границы int64; четвёртая намеренно оставляет продуктовое решение открытым. Политика пилота в `docs/pilot-policy.json` разрешает изменения в `src/` и `tests/`; защищённые файлы и политика требуют отдельного решения владельца. GitHub CI запускает те же проверки на pull request и push в main. Проверки CI не подтверждаются до фактического выполнения GitHub.
